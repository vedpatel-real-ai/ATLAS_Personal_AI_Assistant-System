# Limits of this run

Memory pressure reached warning after the first warm-up. There are zero measured repetitions and no 8B observations. The two models also differ in training or variant as well as size. The single host was already using compressed memory and swap. Endpoint readings capture only the instants sampled, and unrelated applications could affect them. The two-token warm-up cannot estimate sustained generation speed. No scoring rubric, answer grading, responsiveness rating or historical inference record was recovered or generated by this experiment.

A future comparison needs adequate headroom, the complete matched task blocks and a separate run in reverse order. A quality comparison would also need reference answers or independent raters. [Recorded environment](environment.json)
