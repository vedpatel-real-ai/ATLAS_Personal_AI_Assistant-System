# Understanding ATLAS through one request

Imagine typing “what’s my battery?” into a small web page. You want a number from your Mac. Guessing a plausible number would defeat the purpose. ATLAS connects a text interface to functions that can inspect the machine.

| Topic | Simple meaning | Example | Actual ATLAS mechanism | How to say it in an interview |
|---|---|---|---|---|
| Purpose | Use natural language to reach small, inspectable computer actions. | Ask about a repository from the chat page. | The page posts a command to a Python FastAPI handler, much like a React frontend calling a TypeScript API route. [UI](../../chat.html) · [Handler](../../main.py) | “The interesting problem is turning a sentence into an action whose result I can check.” |
| Why use ordinary code? | A predictable request can take a short path. | “What’s my battery?” matches the word “battery.” | A regex matcher emits a tool name and arguments. The handler calls a Python function that queries battery information. Hardware availability affects the result. [Matcher](../../matcher.py) · [Tools](../../tools.py) | “A language model adds little to a request we already recognize.” |
| Why use AI? | Flexible phrasing can make a simple lookup table unwieldy. | Someone describes a repository task in a new way. | The router sends text and tool descriptions to local Ollama and reads a structured decision. It can suggest steps or ask for a direct text response. Both roles specify the same 4B model. [Router](../../router.py) · [Decision code](../../decision_engine.py) | “The model proposes what the words mean. Python decides how to dispatch the result.” |
| What is a tool? | A named function with known arguments and a result. | `read_file(path)` reads text. `index_project(project_path)` counts files by type. | Think of a TypeScript object mapping keys to handlers. The registry has 24 names, including two unfinished integrations. [Registry](../../tools.py) | “A tool gives the assistant access to something it can observe or change.” |
| What does a route label tell us? | It records how the request was handled. | A known phrase takes L0. A routed pair of actions gets L3. | L2 covers a routed single step. L4 is direct reasoning, also selectable from attachment type or size. L1 is reserved. [Labels](../../decision_engine.py) · [Endpoint tests](../../tests/test_main_decision_engine_integration.py) | “There are five labels, and several labels describe decisions within the same execution path.” |
| How does memory work? | SQLite is a local SQL database kept in a file. | “My project” can refer to a recently visited directory. | As with PostgreSQL, records live in tables and queries read them back. ATLAS stores project visits and preferences, and can fill a missing project path for supported tools. It also stores logs, jobs and document summaries. [Memory](../../memory.py) · [Schema](../../storage.py) | “The backend remembers useful application state between requests.” |
| Who approves a risky operation? | The server remembers the exact proposed action while the person reviews it. | Renaming a file uses the caution tier. | The server stores a hash of the proposed steps and issues an expiring token. Confirmation checks the hash, expiry and whether the token has already been consumed. An API key controls access to the endpoints. [Approval code](../../storage.py) · [Tests](../../tests/test_storage_confirmations.py) | “Approval covers the arguments as well as the name of the action.” |
| How is code inspected? | Build a map with a file at each point and an arrow for each resolved internal import. | If A imports B and B imports A, following the arrows leads back to A. | Python’s parser supplies an abstract syntax tree, like the parsed structure behind a TypeScript compiler. JS/TS extraction uses text patterns. An explicit stack walks the graph to find cycles. [Analyzer](../../tools.py) · [Examples](../../tests/test_dependency_graph.py) | “I can show both an edge and the source import that explains it.” |
| What happens to longer work? | A caller can poll a job ID. | A multi-step command can stop before its next action. | Workers run ordered steps and persist progress. Cancellation is checked between steps. Startup marks interrupted jobs failed. [Jobs](../../jobs.py) · [Planner](../../planner.py) | “The job record survives a restart. The original worker thread does not.” |
| What did the experiments investigate? | Adding information, reducing input and improving speed are different questions. | The July document report shortened the prompt while the evaluated token count stayed equal. | The November model experiment captured latency, token counters and host memory. It stopped after a 4B warm-up when pressure rose. [Benchmark evidence](../verification/BENCHMARK_VERIFICATION.md) | “I can point to exactly which quantity changed and where the evidence stops.” |
| What still needs work? | A passing test can verify a contract without verifying a live service or useful answer. | A transcript fixture can check whether text reaches a summarizer, but cannot grade the resulting summary. | Tests isolate Ollama, clipboard and network services. Stock quotes and email return an unfinished status. No paired 8B measurements or scored quality set exist here. [Test inventory](../verification/TEST_VERIFICATION.md) · [Claims](../verification/CLAIM_MATRIX.md) | “I would evaluate routing accuracy and answer quality on labelled requests as separate follow-up experiments.” |
