# ATLAS claim verification matrix

Use the wording in the middle column when discussing the submitted project. This audit evaluates technical statements. Individual authorship and the dates of personal work require the contributor’s own records.

| Claim | Wording supported by the evidence | Evidence and boundary |
|---|---|---|
| 24 tools | 24 registered functions, 22 with substantive implementations. Email and stock quotes return an unfinished result. | [Registry](../../tools.py) · [Result regressions](../../tests/test_verification_contracts.py). Implementation count does not establish 22 live integrations. |
| Five routing levels | L0 matches fixed patterns. L2 labels routed single steps and L3 routed chains. L4 selects direct reasoning. L1 names the concept of a direct tool answer and has no independent execution branch. | [Decision labels](../../decision_engine.py) · [Command handler](../../main.py). ZIP/PDF or large attachment metadata can select L4 before matching. |
| Stronger reasoning model | Router and direct reasoning use the same configured 4B tag. | [Router](../../router.py) · [Reasoning call](../../main.py). Routing roles and model weights are separate design choices. |
| Code dependency analysis | Python imports are parsed with the standard AST library. JS/TS uses import/require patterns. Internal edges, incoming counts, focused lookup and iterative depth-first cycle detection are implemented. | [Analyzer](../../tools.py) · [Real fixture trees](../../tests/test_dependency_graph.py). Dynamic imports, aliases and arbitrary bundler rules can be missed. Scan and example counts are capped. |
| Human approval | Safe, caution and dangerous labels guide dispatch. Caution and dangerous steps require a server-issued, expiring, single-use token bound to the steps. | [Server](../../main.py) · [Token storage](../../storage.py) · [Token tests](../../tests/test_storage_confirmations.py). Shared credentials, local OS privileges and tier assignments limit the protection. |
| Planning, recovery and concurrency | Ordered steps track attempts and outcomes. A designated tool can retry once. Background jobs expose progress and cooperative cancellation. Startup marks orphaned work failed. | [Planner](../../planner.py) · [Jobs](../../jobs.py) · [App](../../main.py). Jobs do not resume execution after a crash. The model lock covers routing and direct reasoning within one process. Tool-internal model calls can overlap. |
| Memory and retrieval | SQLite stores conversations, preferences, project state, logs, summaries, confirmations, jobs and benchmark data. Stored summaries support keyword lookup. | [Storage](../../storage.py) · [Context](../../request_context.py). This is structured persistence and SQL search. |
| 355 tests | 355 original cases passed on 19 November, plus 23 new regression cases in the final run. | [Test evidence](TEST_VERIFICATION.md). Many cases deliberately replace external boundaries. |
| Compared 4B and 8B to select a model | The project supports model evaluation and currently configures a 4B model. Historical selection remains unverified. A fresh 4B warm-up triggered the resource stop. | [Trial and limits](BENCHMARK_VERIFICATION.md). No matched 8B inference or quality comparison. |
| Reduced document input | The July report recorded about 71.5% fewer prompt characters and 2,050 evaluated prompt tokens on each path. | [Historical report](../benchmark-report.md). No demonstrated token or speed gain. |
